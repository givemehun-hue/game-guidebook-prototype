# 게임 공략 서재 — 프로토타입

GitHub Pages에 올릴 수 있는 빌드 없는 정적 HTML/CSS/JS 사이트입니다. 현재 공개하지 않은 초안입니다. `dist/index.html`을 열면 메인 화면을 볼 수 있습니다.

## 범위
- 모바일 우선 반응형 공략집 서가, 장르 필터, 검색
- 검수 PDF → 웹 반영을 위한 빈 카탈로그 구조 (본문 미구현)
- 모든 책은 명시된 UI 예시이며 실제 공략/PDF·세부 페이지 없음
- 외부 폰트, 분석, 사용자 추적, 외부 이미지 없음

## 콘텐츠 운영
1. 공략집 PDF 제작 및 검수.
2. 검수 완료 판본만 content/catalog.json에 등록.
3. 동일한 챕터 ID를 사용하여 웹 내용 구성.
4. PDF와 웹 버전 일치 확인 후 공개.
5. 게임명/플랫폼/버전/출처/이미지 사용권/검수일 명시.

## 게시 전
저장소와 사이트 공개는 별도 결정합니다. Pages는 저장소가 비공개라도 사이트가 공개될 수 있으므로 사이트 접근 정책을 확인해야 합니다. GitHub 플랜의 비공개 저장소 Pages 지원 여부도 확인하세요. 큰 PDF는 Git LFS 대신 별도 배포/파일 저장소 또는 Release 자산을 고려합니다.

공개가 승인되면 새 저장소의 `docs/`에 dist 내용을 복사한 뒤 Settings → Pages에서 main 브랜치 /docs를 선택할 수 있습니다. 이 초안은 자동 배포 워크플로를 포함하지 않습니다.

## 검증
JS 구문 검사 통과. 브라우저에서 375px 모바일 및 1197px 데스크톱 레이아웃의 수평 넘침 없음 확인. 모바일 단일 열 배치, 장르 필터, 검색과 빈 결과 안내 동작 확인. 실제 iPhone Safari 실기 검증은 아직 하지 않았습니다.
